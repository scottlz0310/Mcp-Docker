# diff外の影響確認（O-05）

変更箇所の正しさに加え、変更されていない利用側の前提が維持されるかを確認する。初回はIndependent Stageで既存レビュー本文を読まずに実施し、再レビューは下記の対象範囲に絞る。取得・比較・検索はSnapshot Guardで固定した環境とSHAを使う。

## 変更した前提から利用経路を追う

1. 完全diffから、既存の利用側が依存する前提の変更を特定する。名前・シグネチャだけでなく、戻り値、エラー、既定値、設定キー、保存形式、実行順序・副作用も見る。
2. その前提に依存する箇所を、固定したrepository内で`rg`等により検索する。呼び出し元だけでなく、データの読込・書込、設定・登録、CI・配布経路も変更内容に応じて探す。削除・改名は旧名称でも検索し、必要なら固定diffの変更前と比較する。
   ```bash
   rg -n -F -e '変更前の名前やキー' -e '変更後の名前やキー' . --hidden -g '!.git'
   ```
   これは検索の例であり、文字列を実際の変更に置き換える。無視対象の設定ファイル等が利用経路にあれば、そのpathを明示して別途確認する。検索ヒットなしを影響なしの根拠にせず、登録・動的参照・生成元も必要に応じて追う。
3. diff外の該当箇所と周辺処理を実際に開き、入口から変更箇所、その結果を使う処理まで具体的な経路を追う。「変更箇所は正しくても、既存の利用側で壊れる条件はないか」を確認する。検索結果の一覧やファイル名だけでは確認済みにしない。
4. 利用側の前提が維持される根拠、または破綻する入力・状態と影響まで確かめ、必要な検証を行う。例えば空配列から`null`への変更なら利用側の列挙処理、設定キー変更なら既存設定の読込・移行・配布設定を確認する。PR以前からの問題と今回の変更による回帰を区別する。

## 探索を終える判断

- 変更した前提ごとに、利用経路で成立する根拠か破綻条件が得られれば、その経路の確認を終える。未確認の分岐は確認済みに含めない。
- 参照が多い場合は同一パターンの代表経路を確認できる。同じ前提が成立すると判断した根拠と選定理由を残し、残りは未確認範囲として明記する。異なるエラー処理・実行環境・データ形式の経路を同一視しない。参照数だけで打ち切らない。
- 承認判断に必要な重大な不確実性が残る場合は追加確認する。確認できなければ残存リスクに記録し、既存のVerdict基準に従って`comment only` / `needs follow-up`とする。確認したblockingがあれば`request changes`とする。リスクの記載だけで承認条件を満たしたことにしない。
- 契約・前提を確認して変更がないと判断した場合は「前提変更なし（理由: ...）」だけでよく、表を埋めるための探索は不要。内部実装やドキュメントというファイル種別だけでは判断しない。内部処理でも副作用等、ドキュメントでも利用手順・運用上の前提が変わり得る。

## 再レビューの対象範囲

未解決thread、対応差分が新たに変えた前提と重大な回帰に加え、前回の未確認範囲のうち、当該PRが変えた前提に関係し破綻時の影響が大きい経路を確認する。既に根拠を確認した経路を理由なく再探索せず、軽微な後出し指摘やPR目的外の監査へ広げない。

前回の確認記録は再レビュー開始時にコメントとともに読む。記録がない場合は未確認範囲を推測で補わず、記録なしと明記し、対応差分と既存指摘から影響を確認する。

## 確認範囲の記録

初回・再レビューとも、指摘ゼロでも次の形式で短く残す。これは確認範囲の証跡であり、既存レビューとの重複を扱う`Independent review delta`とは分ける。

```markdown
### diff外の影響確認

| 変わった前提 | 確認した利用経路・位置 | 確認結果・根拠 |
| --- | --- | --- |
| ... | path:line → path:line | 成立の根拠、または破綻条件・影響 |

- 代表経路の選定理由・同一パターンとみなす根拠: ...（該当時のみ）
- 未確認範囲・残存リスク: ...（なければ「なし」）
```

前提変更なしの場合は表を省き、同じ見出しの下に理由を記載する。未実施は前提変更なしと区別し、理由と未確認範囲を残す。

この記録をユーザー報告と、通常終了のO-12の完了通知1件に含める。approve時はVerdictの自由記述`summary`に含め、それ以外はReview Resultに含める。別コメントを途中投稿しない。再レビューでは今回確認した範囲と引き続き未確認の範囲を区別し、次回にも引き継げるようにする。
